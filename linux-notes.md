# Linux Navigation Notes

## Goal
Understand how to find my location, list directory contents, and move between directories.

## Commands

| Command | Purpose | Memory cue |
| --- | --- | --- |
| pwd | Shows the full path of my current directory | Where am I? |
| ls | Lists visible files and folders in my current directory | What is here? |
| cd Documents | Moves into a Documents folder inside my current directory | Move here |
| cd .. | Moves up one directory level | Go up |

## Important Details
- A directory is another word for a folder.
- Linux filenames are case-sensitive.
- Documents and documents can be different directories.
- cd Documents works only if that folder exists in my current location.

## Practice Checklist
- [ ] Run pwd and explain the output.
- [ ] Run ls and identify the listed items.
- [ ] Move into an existing folder using cd.
- [ ] Run pwd again to confirm the new location.
- [ ] Use cd .. to move up one level.
